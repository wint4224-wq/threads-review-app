# 스레드 초안함

블로그 새 글로 만든 스레드 초안을 폰에서 검토, 수정하고 게시하는 웹앱입니다. `index.html` 한 파일로 동작하며 서버와 외부 라이브러리가 없습니다.

- 초안은 비공개 저장소에 있고, 이 앱은 사용자가 입력한 GitHub 토큰으로만 읽습니다.
- 아이디, 저장소 이름, 토큰은 코드에 들어 있지 않고 그 기기의 브라우저에만 저장됩니다.
- Content-Security-Policy로 네트워크 연결을 `https://api.github.com`으로만 제한합니다.
- 토큰은 브라우저 저장소에 평문으로 남습니다. 공용 기기에서는 쓰지 말고, 기기를 잃어버리면 GitHub에서 토큰을 바로 삭제하세요.
